Model Architecture

1. Deep LSTM Formulation

Multi-layer LSTM gating regulates temporal memory across 24-hour lookback windows:

f_t = σ(W_f · [h_{t-1}, x_t] + b_f)   (Forget Gate)
i_t = σ(W_i · [h_{t-1}, x_t] + b_i)   (Input Gate)
C_t = f_t ⊙ C_{t-1} + i_t ⊙ Č_t   (Cell State)
h_t = o_t ⊙ tanh(C_t)   (Hidden Output)

2. Asymmetric SLA Loss Penalty

Penalizes under-prediction 2.5x more heavily than over-prediction:

L_SLA(y, ŷ) = &frac1N ∑ w_i · (y_i - ŷ_i)^2
where w_i = 2.5 if y_i > ŷ_i (traffic exceeds headroom), else 1.0
